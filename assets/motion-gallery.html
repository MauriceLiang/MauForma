官方 API 与设计配方需区分。 Anime.js 提供的是动画属性、时间轴、拖拽、布局、SVG、文字与缓动工具，不是预装 114 个特效。这里的 114 种效果是本 Skill 归纳的组合方案。复杂场景的预览是原理示意；要投入产品，应按对应 API 章节真实实现并测试。正在检测演示引擎…

以下为 Anime.js 官网 v4 文档列出的 45 个内置缓动名称（1 个 linear、4 个 Power 变体及 10 个家族 × 4 个变体）。旁边的运动只是位置与节奏原理演示，完整函数曲线以官网缓动编辑器为准。

扩展生成器： cubicBezier()、linear()、steps()、irregular()、spring({ bounce, duration })、spring({ mass, stiffness, damping, velocity })。它们可连续调参，不是数量固定的视觉特效。
